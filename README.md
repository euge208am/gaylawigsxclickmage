# Gayla Wigs · Creative Direction

Static presentation site for Gayla Wigs: brand identity, campaign banners and a website concept.

## Pages
- `/` home
- `/branding` logo, palette, typography, photography, voice
- `/banners` the 10 campaign banners, with a large view and PNG download
- `/website` the homepage concept inside a browser frame
- `/landing` the homepage concept, full page

## Fonts
- IvyJournal comes from an Adobe Fonts kit. In each HTML file, replace `KIT_ID` in the commented `use.typekit.net` link and uncomment it. Until then, headlines fall back to Cormorant Garamond.
- Helvetica uses the system font.
- Monsieur La Doulaise comes from Google Fonts.

## Deploy
Plain HTML, CSS and JS with no build step. On Vercel, import the repository with the default settings; `vercel.json` turns on clean URLs.
